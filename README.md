# Skinstric AI

A frontend clone of the Skinstric AI skincare analysis site, built for the
Frontend Simplified internship program.

**Live:** https://skinstric-rosy.vercel.app

## Stack

- Next.js 16 (App Router)
- TypeScript
- TailwindCSS v4
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
